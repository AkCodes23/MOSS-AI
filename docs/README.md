## Suggested order

**Completely new to AI?** [Get Started with AI](get-started-with-ai.md) →
[Generative AI: An Overview](generative-ai-overview.md) →
[Generative AI In Depth](generative-ai-in-depth.md).
About an hour end to end, and you'll be able to follow most AI conversations afterwards.

**About to contribute?** [Git and GitHub](git-and-github.md) first, then
[CONTRIBUTING.md](../CONTRIBUTING.md).

**Planning a study path?** [AI Syllabus](ai-syllabus.md) is the checklist; the
[roadmap](../README.md#learning-roadmap) is the schedule. Use them together — the syllabus tells
you what exists, the roadmap tells you what order to meet it in.

## Adding an explainer

Prose that teaches a concept belongs here. Code that demonstrates one belongs in
[`notebooks/`](../notebooks/); a link to someone else's writing belongs in the
[main README](../README.md#resource-library).

- Lowercase, hyphen-separated filename
- Open with an H1 title and a one-line summary of what the reader will know afterwards
- Write for someone who has never seen the topic before
- Link the sources you learned it from at the end
- Add a row to the table above and to [the main README](../README.md#explainers)

See [CONTRIBUTING.md](../CONTRIBUTING.md).
