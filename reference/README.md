## How to use these

Cheat sheets are for **recall**, not learning. Read a chapter or watch a lecture first; use these
to refresh what you already met once.

`ml-cheatsheet.pdf` is the broadest — keep it open in a second window while working through the
[notebooks](../notebooks/). The topic-specific notes are better after you've finished the matching
notebook, as a consolidation pass.

For depth rather than density, go to the [books](../README.md#books) — several are free.

## Adding a PDF

- Descriptive lowercase filename: `attention-notes.pdf`, not `notes_final_v2.pdf`
- Add a row above with the page count and one line on what it covers
- Only add material you have the right to redistribute. For copyrighted books, link to the
  publisher's page in the [main README](../README.md#books) instead of committing the file
- Keep it under ~10 MB where you can — every clone pays for it
